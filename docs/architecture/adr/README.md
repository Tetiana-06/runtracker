# Реєстр архітектурних рішень (Architecture Decision Records — ADR)

Цей каталог містить формальні записи ключових архітектурних рішень системи **RunTracker**, оформлені за стандартом Лекції 8.

## Правило незмінності історії (Immutability Policy)
> Записи ADR фіксують стан та аргументацію на момент ухвалення рішення і **ніколи не переписуються заднім числом**.  
> Якщо ухвалене раніше рішення втрачає актуальність через зміну бізнес-вимог чи технологічного стеку, створюється новий ADR із новим номером, а попередній позначається статусом `Superseded` із прямим посиланням на наступника.
